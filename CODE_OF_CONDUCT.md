# Code of Conduct

This project expects respectful, professional collaboration.

## Our standards

Examples of expected behavior:

1. Be clear, technical, and constructive.
2. Assume good faith and discuss disagreements with evidence.
3. Focus criticism on code, design, and process rather than people.
4. Respect time, attention, and the boundaries of other contributors.

Examples of unacceptable behavior:

1. Harassment, threats, or personal attacks.
2. Discriminatory or demeaning language.
3. Deliberate disruption of discussions, reviews, or issue tracking.
4. Publishing private information without permission.

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and other project communication channels.

## Enforcement

Project maintainers may remove, edit, or reject comments and contributions that do not meet these standards.
