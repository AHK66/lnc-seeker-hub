📍 Coordinate System & Geometry

Coordinates in the lncRNA Seeker Hub are zero-based, half-open: features use the interval $$[start, end)$$. An exon from $$100$$ to $$200$$ covers bases 100–199 and has length $$end - start$$.

Introns are derived as the gaps between exon blocks (start = end of the upstream exon, end = start of the downstream exon) and use the same 0‑based, half‑open coordinates. For example, two exons $$[100,200)$$ and $$[300,400)$$ imply an intron $$[200,300)$$.

Quick conversion (0-based half-open ↔ 1-based inclusive):
  • 0-based, half-open $$[start,end)$$: includes start, excludes end. Length = end - start. Example: $$[100,200)$$ covers bases 100–199 (100 bp).
  • 1-based, inclusive $$[a,b]$$: includes both endpoints. Length = b - a + 1. The previous example is $$[101,200]$$ in 1-based coordinates.
  • Convert: 0→1: start1 = start0 + 1, end1 = end0. 1→0: start0 = start1 - 1, end0 = end1.

Most genome browsers (for example, IGV) show 1-based inclusive coordinates.
Expect a 1‑bp offset of the start coordinate when copying coordinates between the Hub and 1-based tools—this is normal.

🚀 Getting Started

  1. Select a gene: Use the dropdown in the left sidebar. The Hub dynamically loads and caches data for the selected locus.
  2. Choose samples: Use either the Sample Selection combo box or the Sample Cohorts list on the right. After selecting samples, the Coverage Plot and Junction Profiles will replace the Sample Selection page.
  3. Interact with junctions: Click splice‑junction arcs to view read support, or use the context menu to add them to your analysis.

📖 Key Features & Manual

  • Navigation & Zoom: Use Ctrl + Mouse Wheel over any axis to zoom. Drag to pan. All plots (Annotations, Coverage, Reads) are perfectly synchronized.
  • Advanced Filtering: Use the sidebar to filter by Mapping Quality, Minimum Reads, or toggle Mismatch/Insertion Flank Filtering to isolate high-confidence events.
  • Comparative Logic: Define rules to highlight junctions present in specific groups and missing in others—ideal for identifying novel splicing patterns.
  • Full Read Layout: Visualize individual read alignments to verify the physical co-occurrence of multiple splicing events.
  • Transcript Creator: Manually architect hypothetical transcripts and "inject" them into the visualization to test your hypotheses against the experimental evidence.
